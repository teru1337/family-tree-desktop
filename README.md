# Локальное семейное древо

Локальное Windows-приложение для хранения и визуализации семейного дерева.

## Текущий этап

Этап 29 — источники сведений, достоверность и явные записи неизвестных людей. GitHub Actions собирает
установщик по тегу версии, а установленное приложение проверяет GitHub Releases
при запуске и предлагает скачать новую версию.

## Принципы

- приложение работает без обязательного подключения к интернету;
- все поля о человеке необязательны;
- неполные и приблизительные сведения сохраняются без принудительного уточнения;
- новые фотографии встраиваются внутрь файла проекта, а старые внешние пути помечаются
  предупреждением при проверке;
- структура данных версионируется, чтобы резервные копии можно было восстанавливать после обновлений приложения.
- резервная копия создаётся автоматически и может быть восстановлена из интерфейса.
