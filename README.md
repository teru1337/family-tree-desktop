## Что это такое

«Семейное древо» — бесплатное desktop-приложение для Windows, которое помогает собирать
семейную историю в одном понятном визуальном пространстве.

Проект создан с принципом **local-first**: основная работа и хранение данных происходят
на компьютере пользователя. Интернет нужен только для проверки обновлений, если она доступна.

> Семейные данные остаются вашими. Регистрация, подписка и обязательное облачное хранилище
> не нужны.

## Скачать и установить

1. Откройте [страницу релизов](https://github.com/teru1337/family-tree-desktop/releases).
2. Выберите самый новый релиз с пометкой **Latest**.
3. В разделе **Assets** скачайте файл `FamilyTree-Setup-*.exe`.
4. Запустите установщик и следуйте его шагам.

Для обычной установки нужен именно файл `.exe`. Файлы `.blockmap` используются приложением
для обновлений, а `Source code` содержит исходный код проекта и не предназначен для установки.

Если Windows покажет предупреждение SmartScreen, убедитесь, что файл скачан с официальной
[страницы Releases](https://github.com/teru1337/family-tree-desktop/releases), и продолжайте
установку только если доверяете этой сборке.

## Возможности

### Семейное дерево

- полное дерево и режим ближайшей семьи;
- панорамирование полотна, масштабирование и мини-карта;
- поиск человека по имени, месту, профессии, биографии и другим сведениям;
- кнопка «Показать найденного человека на карте»;
- перемещение карточек внутри своего поколения;
- фотографии на карточках и несколько вариантов оформления.

### Люди и связи

- пошаговое добавление человека сразу в нужное место дерева;
- необязательные поля: ФИО, даты, место рождения, профессия, фото и биография;
- точные, годовые, приблизительные, диапазонные и неизвестные даты;
- биологическое родство, усыновление, опека и степ-родство;
- супруги, партнёры, браки, разводы, братья и сёстры;
- уникальный ID каждой записи и связи;
- просмотр взаимных ролей: кто кем приходится другому человеку;
- калькулятор родства между двумя людьми.

### Надёжное хранение

- локальный файл проекта `.familytree`;
- версионирование формата и проверка целостности;
- фотографии, источники сведений и события внутри проекта;
- автоматические резервные копии;
- проверка копии перед восстановлением;
- архив материалов `.familyarchive` для переноса на другой компьютер;
- отмена и повтор последних действий;
- новое дерево открывается пустым, без демонстрационных записей.

### Экспорт и печать

- PNG для семейного альбома;
- TIFF для типографии;
- PDF для просмотра, плаката или многостраничной печати;
- большой плакат со всем деревом на одном листе;
- разбиение дерева на листы A4, A3 или A2;
- настройка качества, размеров карточек, шрифта, расстояний и плотности связей;
- предпросмотр результата до создания файла.

## Быстрый старт

1. Нажмите **Создать древо**.
2. Добавьте первого человека — даже если известны только отдельные сведения.
3. В мастере выберите связь с уже добавленным человеком или сохраните запись без связи.
4. Заполните известные поля и добавьте фотографию при необходимости.
5. Перемещайтесь по дереву, выбирайте людей и добавляйте следующие связи.
6. Сохраните проект в файл `.familytree`.

Все поля необязательны: неизвестные сведения можно оставить пустыми и дополнить позже.

## Как не потерять семейную историю

Файл проекта — это ваша основная копия. Для дополнительной защиты:

- сохраняйте копию `.familytree` на внешнем диске или флешке;
- периодически создавайте полный `.familyarchive`;
- храните резервную копию отдельно от компьютера;
- перед переносом на другой компьютер проверяйте, что архив открывается;
- не добавляйте личные семейные файлы в публичный репозиторий GitHub.

Приложение создаёт локальные автоматические копии, но внешняя копия нужна на случай
поломки компьютера, повреждения диска или случайного удаления файла.

## Обновления

Приложение проверяет GitHub Releases при запуске. Если найдена новая версия, оно показывает
уведомление и предлагает скачать обновление. После загрузки обновление устанавливается
в фоновом режиме, а приложение перезапускается уже с новой версией.

Все доступные установщики и заметки об изменениях находятся на странице
[Releases](https://github.com/teru1337/family-tree-desktop/releases).

npm test
