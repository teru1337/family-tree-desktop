# Этап 41. Расширенный поиск семейных сведений

## Сделано

- Строка поиска теперь ищет не только по имени, месту и году, но и по профессии,
  биографии, девичьей фамилии, источникам, событиям временной шкалы и дополнительным полям.
- В фильтры поиска добавлены отдельные поля «Профессия», «Биография», «Источник» и выбор
  «Только с фотографией» или «Только без фотографии».
- В поиск включены источники фактов, событий, родительских и партнёрских связей.
- Для поиска используется единая нормализация регистра, пробелов и букв «ё/е».
- Длинный список фильтров прокручивается внутри панели и не закрывает всё рабочее полотно.

## Проверка

- `stage-41-search-fields.test.mjs` проверяет полнотекстовый поиск, точные фильтры,
  источники, фотографии и наличие новых элементов интерфейса.
