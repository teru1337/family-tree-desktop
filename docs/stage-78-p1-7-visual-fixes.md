# Этап P1.7 — подписи брака, стартовая анимация и ошибка updater

Дата: 26.08.2026

## Исправления

- Подписи брака на полотне и в экспорте закреплены над верхним левым краем
  карточки пары, а не в нижнем канале между поколениями.
- Полная подпись по нажатию сохраняет верхний канал и продолжает участвовать в
  расчёте свободного места для смещения поколения.
- Вход стартового меню сделан медленнее: карточка плавно поднимается снизу,
  слегка замедляется и занимает центральное положение.
- Фон стартового меню продолжает циклически двигать ветви, листья, карточки и
  частицы после завершения входа.
- Ошибки обновления больше не показывают пользователю stack trace и заголовки
  HTTP. Для отсутствующего `latest.yml` выводится короткое действие.
- Для текущего GitHub Release должен быть опубликован `latest.yml`; без этого
  `electron-updater` не может проверить обновление.

## Проверка

- Добавлен регрессионный тест этапа 78.
- Проверяется общий якорь подписей полотна и экспорта.
- Проверяется длительность входа и бесконечные фоновые анимации.
- Проверяется сокращение ошибок updater.

Формат `.familytree` не менялся. Реальный пользовательский файл в репозиторий
не добавлялся.
