# Этап 34. Понятный мастер добавления человека

Задача по поддержке неполных и сложных семейных ситуаций выполнена.

## Что сделано

- Добавлен отдельный сценарий «Неизвестный родитель»: создаётся связанная запись
  без обязательного имени, которую можно заполнить позже.
- Для ребёнка добавлены отметки «Известен только один родитель» и «Ребёнок вне
  брака». Они сохраняются в проекте и показываются в карточке человека.
- Для брата или сестры добавлен понятный сценарий создания связи без указания
  родителей.
- Повторное добавление сохраняет выбранный тип связи и исходную цель. Поэтому
  можно подряд добавлять нескольких детей, братьев/сестёр или партнёров, не
  создавая связь с последней добавленной записью по ошибке.
- В шаге проверки теперь явно показываются связь и выбранная семейная ситуация.
