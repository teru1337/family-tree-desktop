# Этап 33. Калькулятор родства

Задача «Калькулятор родства между двумя людьми» выполнена.

## Что сделано

- Добавлен расчёт по текущему локальному дереву без аккаунта и интернета.
- Поддержаны прямые связи: родитель, ребёнок, отчим/мачеха, пасынок/падчерица,
  усыновление, опека, супруг/супруга и партнёр.
- Добавлено определение родства через поколения: дедушка и бабушка по материнской
  или отцовской линии, внуки, дяди/тёти, племянники и двоюродные родственники.
- Для сложных случаев показывается полный путь между двумя людьми, включая тип
  каждой связи.
- Калькулятор доступен из карточки выбранного человека и из меню «…».
- Нажатие на человека в пути закрывает окно и открывает его карточку в приложении.
- Добавлена обработка одинакового человека и людей из несвязанных веток.

## Проверка

- `npm test` — 43 теста проходят.
- `npm run build:renderer` — production-сборка проходит.
- Добавлены отдельные тесты для прямой связи, родства по линии предков, двоюродного
  родства, несвязанных веток и пользовательского интерфейса.
