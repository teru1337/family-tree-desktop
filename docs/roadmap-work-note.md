# Рабочая заметка по дорожной карте

Дата фиксации: 25.08.2026.

После релиза v0.3.0 блок исправлений P0–P3 завершён 25.08.2026: P0.1, P0.2,
P1.1, P1.2, P1.3, P2.1, P2.2, P2.3, P3.1 и P3.2 закрыты. Следующий этап
требует отдельного обновления дорожной карты.

Текущий порядок:

- P0.1 — завершён: незадачивающийся геокодер Яндекса и актуальный адаптер ответа;
- P0.2 — завершён: нативный путь, `Ctrl+S`, атомарная запись, боковая копия и безопасный «Сохранить как»;
- P1.1 — завершён: единые border-box/anchor-точки линий и стабильные размеры карточек;
- P1.2 — завершён: общий раскладчик подписей, каналы с минимальными зазорами,
  увеличенный зазор партнёров и одинаковая разметка полотна/экспорта;
- P1.3 — завершён: обезличенный четырёхпоколенный fixture, проверки плотной
  геометрии, крупного текста, ветви и ширины инспектора;
- P2.1 — завершён: IDs только внутри данных, не в обычном UI; пользовательские
  диагностические сообщения не раскрывают технические ключи;
- P2.2 — завершён: библиотечные CaretRight/CaretDown, оптическое центрирование
  и отдельные размеры для обычного и крупного текста;
- P2.3 — завершён: цифровая маска `__.__.____`, вставка из буфера, курсор и
  календарная blur-валидация точной даты рождения;
- P3.1 — завершён: масштабирование колесом относительно курсора, горизонтальная
  панорама через `Shift+колесо` и горизонтальный тачпад; мини-карта и правая
  панель не затронуты;
- P3.2 — завершён: единый реестр команд, изменение и сброс сочетаний, проверка
  конфликтов, защита от Windows-глобальных сочетаний и инструкция в настройках;
  старые проекты получают безопасные значения по умолчанию.
- P1.4 — в работе: верхний канал подписей брака, расчёт по полному тексту и
  совместное смещение поколения с потомками при раскрытии.

Нельзя коммитить реальный файл пользователя. Нельзя менять формат проекта без
миграции. Каждый подэтап требует тестов, production-сборки, визуальной проверки,
отдельного commit и push. Релиз не создавать без прямого запроса.
