Дата фиксации: 25.08.2026.

следующий этап — P0.2.

- P1.3 — обезличенный плотный fixture и визуальные регрессии;
- P2.1 — IDs только внутри данных, не в обычном UI;

миграции. Каждый подэтап требует тестов, production-сборки, визуальной проверки,
