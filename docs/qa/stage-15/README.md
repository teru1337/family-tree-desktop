# QA — этап 15

Проверяется инструкция с реальными снимками текущего приложения и отдельными
SVG-аннотациями.

## Сценарий

1. Открыть локальное приложение и открыть «Инструкцию для пользователей».
2. Последовательно проверить все восемь шагов.
3. Убедиться, что меню, панель, карточки, фотографии и окна совпадают с текущим
   интерфейсом приложения.
4. Проверить, что каждая стрелка заканчивается у нужного элемента, а подписи не
   закрывают элементы снимка.
5. Проверить навигацию «Назад», «Далее», индикаторы, боковой список и закрытие.

## Результат

- 8 реальных локальных снимков сохранены в `prototype/public/instruction/`;
- 8 SVG-аннотаций используют соответствующие снимки;
- тест ассетов и production-сборка проходят.
