# Этап 5. Визуализация

## Полное дерево

Полотно строится по текущему списку людей проекта, а не по фиксированному набору
демонстрационных карточек. Для каждой записи рассчитывается поколение по родительским
связям. Супруги и партнёры выравниваются в одной группе, чтобы семейные пары не
разъезжались по вертикали.

На полотне отображаются:

- все люди, включая добавленные записи;
- подписи поколений;
- родительские связи;
- усыновительские связи пунктирной линией;
- браки, партнёрства и разводы.

## Навигация

- стрелки слева перемещают полотно вверх, вниз, влево и вправо;
- полотно можно перетаскивать мышью;
- масштаб изменяется кнопками от 55% до 135%;
- кнопка с прицелом возвращает масштаб 100% и положение по центру.

## Фотографии

Фотография человека показывается на карточке дерева, если она есть. Для новых людей
без фотографии используется нейтральный значок. В меню «⋯ → Настроить вид дерева» фото
можно временно скрыть, чтобы освободить место на большом полотне.

## Стили

Доступны три оформления:

- «Классический» — текущая спокойная схема с зелёными акцентами;
- «Семейный альбом» — тёплая бумажная палитра и цветные фотографии;
- «Сдержанный» — светлая холодная схема с минимальным декором.

Настройка влияет только на отображение и не меняет данные проекта.

## Ограничения прототипа

- автоматическая оптимизация расположения больших сложных деревьев ещё не реализована;
- пользователь пока не может вручную закрепить позицию отдельной карточки;
- экспорт большого полотна в PDF и изображение остаётся задачей следующего этапа;
- настройки вида пока действуют только в текущем запуске прототипа.
