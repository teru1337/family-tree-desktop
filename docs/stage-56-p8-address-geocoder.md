# Этап 56 — P8: поиск адреса

## Что сделано

- Добавлен отдельный адаптер геокодера с начальным провайдером Яндекс.
- Поиск запускается только явной кнопкой «Найти адрес»; ввод текста сам по себе
  не отправляет запрос.
- При первом поиске ключ запрашивается через диалог приложения и хранится только
  в памяти текущего сеанса. Ключ не попадает в `.familytree`, рабочую копию,
  резервные копии или экспорт.
- Ответ провайдера приводится к общей модели подсказки: исходная строка,
  населённый пункт, регион, страна, широта, долгота и источник.
- Выбранная подсказка сохраняет исходный текст места рождения и структурированные
  `placeDetails`; ручное изменение строки очищает старую подсказку, чтобы не
  осталось противоречивых координат.
- Добавлены локальный кэш подсказок с ограниченным размером и ограничение частоты
  запросов.
- При отсутствии сети, ключа, настроенного сервиса или превышении лимита форма
  оставляет полностью рабочий ручной ввод.
- Поиск и фильтр людей учитывают населённый пункт, регион и страну из выбранного
  адреса.

## Формат и совместимость

Номер формата `.familytree` не изменён: `placeDetails` необязателен и добавляется
только после выбора подсказки. Старые проекты с обычной строкой места рождения
открываются без миграции и без добавления пустых структурированных полей.

Секрет API дополнительно удаляется из настроек при сериализации даже если он
попал туда из внешнего или повреждённого входного объекта.

## Проверка

- `npm test` — 125 тестов, включая P8.
- `npm run build:renderer` — production-сборка, Sites-подготовка и renderer-бюджет:
  `499641 / 500000` байт.
- Браузерная проверка подтвердила наличие поля адреса, кнопку поиска и её
  отключение до ввода минимум трёх знаков; после ввода «Кемерово» кнопка стала
  активной.

## Ограничения и следующий шаг

Первый провайдер и endpoint пока зафиксированы на Яндекс Геокодере; расширение
списка провайдеров возможно через уже выделенный адаптер. Реальный запрос требует
ключа пользователя и явного нажатия кнопки. Следующий этап по дорожной карте —
приоритет 9: происхождение сведений, журнал изменений, дополнительные проверки
противоречий, сворачивание ветвей, экспортный паритет и доступность.
