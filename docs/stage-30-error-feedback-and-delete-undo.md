# Этап 30: понятные ошибки и отмена удаления

Выполнено:

- Ошибки открытия, сохранения, восстановления, автосохранения, экспорта и обновления теперь показывают причину и следующее действие.
- Ошибки JSON и файлов `.familytree` получают понятное объяснение без технического сообщения для пользователя.
- В редакторе семейных связей добавлен список существующих связей и удаление выбранной связи через подтверждение.
- После удаления человека или связи появляется кнопка «Отменить», которая использует общую историю действий.
- Перед удалением по-прежнему создаётся локальная резервная копия.

Проверка: 33 теста и production-сборка renderer проходят успешно.
