# Этап P1.6 — стартовое меню

Дата: 25.08.2026  
Статус: реализован; визуальная проверка ожидает запуска на Windows с рабочим GPU

## Что сделано

- Окно Electron запускается с `frame: false`, `fullscreen: true` и
  `fullscreenable: true`. Убран прежний вызов `maximize()`, который создавал
  только максимизированное окно с другой моделью поведения.
- Главное меню занимает весь экран и появляется снизу плавной анимацией.
- На задний план вынесен отдельный декоративный слой с ветвями, листьями,
  линиями связей, полупрозрачными карточками и частицами. Он не перехватывает
  клики и не смешан с данными семейного дерева.
- Добавлена кнопка «Пропустить анимацию». Она мгновенно завершает появление
  меню и отключает декоративное движение; после естественного завершения
  вступительной фазы кнопка скрывается автоматически.
- При `prefers-reduced-motion: reduce` бесконечные движения фона отключаются,
  но плавное появление самого меню сохраняется, как согласовано.

## Сохранность данных и совместимость

Этап не меняет структуру проекта, связи, идентификаторы или сохранение
`.familytree`. Реальный пользовательский файл в репозиторий не добавлялся и не
изменялся.

## Проверки

- `npm test`
- `npm run build:renderer`
- `git diff --check`
- статические тесты отдельно проверяют полноэкранный контракт, состав сцены,
  кнопку пропуска и reduced-motion-правило;
- попытка визуального запуска Electron в текущей среде завершилась до показа
  окна с ошибкой GPU (`GPU process isn't usable`), поэтому визуальная проверка
  не объявляется выполненной и должна быть повторена на обычной Windows-системе.
