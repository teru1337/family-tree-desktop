# Этап 7 — проверка на большом тестовом дереве

## Граница проверки

Реальные семейные данные в проект не передавались, поэтому для безопасной проверки
использован отдельный синтетический файл
`prototype/test-data/stage-7-synthetic.familytree`. Он содержит:

- 37 человек;
- 5 поколений;
- 9 браков и партнёрств;
- неполные ФИО, даты и места рождения;
- приблизительные и неизвестные даты;
- усыновительскую связь;
- завершённое партнёрство с разводом.

Тестовый файл не заменяет будущую загрузку настоящих данных семьи: он нужен только
для воспроизводимой проверки приложения.

## Пройденные сценарии

1. Открыт файл из папки проекта — отображаются 37 карточек без ошибок.
2. Найдена запись без ФИО и даты рождения.
3. Неполная запись изменена: добавлены имя, приблизительная дата и место рождения.
4. Добавлен новый человек только с ФИО — число записей увеличилось до 38.
5. В редакторе связей добавлено усыновление.
6. Для активного партнёрства отмечен развод с годом 2012.
7. Создано несколько автокопий; список ограничен 10 последними записями.
8. Внесено намеренно ошибочное имя, затем восстановлена предыдущая автокопия.
9. После перезапуска рабочая копия снова открылась с 37 людьми и восстановленными связями.

## Найденные и исправленные ошибки

- Записи без ФИО нельзя было найти. Поиск теперь учитывает название «Человек без
  имени», место рождения и дату.
- В карточке выбранного человека пустое ФИО отображалось пустым заголовком. Теперь
  показывается понятная подпись «Человек без имени».
- В нижней строке было зашито значение «4 поколения». Теперь число поколений
  рассчитывается по текущему дереву.

## UX-наблюдения

- Редактор прямо сообщает, что все поля необязательны; неполную запись можно сохранить.
- Список резервных копий показывает время, причину и количество людей, поэтому нужную
  копию можно отличить без открытия файла.
- Для большого дерева добавлены панорамирование и явная кнопка «Показать найденного
  человека на карте»; дальнейшая проверка удобства нужна на реальных данных семьи.
