# Этап 42. Навигация и режим ближайшей семьи

## Сделано

- Добавлена история переходов между карточками людей с ограничением размера, чтобы
  приложение не накапливало бесконечный список.
- В правой панели появились кнопки «Предыдущий» и «Следующий». Переходы по результатам
  поиска, родственникам и кнопке показа на карте сохраняются в истории.
- Добавлен переключатель вида дерева «Всё дерево / Ближайшая семья».
- Режим ближайшей семьи показывает выбранного человека, его родителей, детей, братьев и
  сестёр, супругов или партнёров. Связи с невидимыми карточками в этом режиме не рисуются.
- Мини-карта продолжает показывать всё дерево, чтобы пользователь не терял общий контекст.
- При переключении на ближайшую семью выбранный человек автоматически оказывается в центре.

## Проверка

- `stage-42-navigation-family-view.test.mjs` проверяет историю переходов, состав ближайшей
  семьи и элементы интерфейса.
- Дополнительно проверены производительность виртуализации дерева, поиск и мини-карта.

основных действий.
