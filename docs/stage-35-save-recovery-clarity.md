# Этап 35. Понятное сохранение и восстановление

Задача по отображению текущего файла, резервных копий и проверке восстановления
выполнена.

## Что сделано

- В установленной Windows-версии добавлено системное окно сохранения проекта.
- Приложение запоминает выбранный полный путь и повторно сохраняет проект в этот
  файл без лишних скачиваний.
- В нижней строке и окне резервных копий показываются имя проекта, имя файла,
  путь, время последнего сохранения и время последней локальной копии.
- Для режима браузера сохранён fallback: проект скачивается обычным способом,
  а интерфейс честно сообщает, что точный путь браузеру неизвестен.
- Перед восстановлением копия повторно проверяется через нормализацию и проверку
  формата, количества людей и связей.
- Восстановление повреждённой копии блокируется; корректную копию нужно явно
  подтвердить отдельной кнопкой.
