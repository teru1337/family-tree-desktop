# Этап 69 — P2.1: скрытие технических идентификаторов

Дата: 25.08.2026

## Что изменено

- Убрана секция «Идентификаторы» из правой панели выбранного человека.
- Убрана отдельная строка с ID связи из списков родителей, супругов и партнёров,
  братьев и сестёр, а также детей.
- Из пользовательских диагностических сообщений убраны значения ID людей,
  связей и фотографий. В сообщениях остались понятные номера записей и описание
  проблемы.
- Обновлена подсказка раздела связей: технические ключи описываются как
  внутренние и не показываются пользователю.
- Поля `id`, каноническая таблица `relations`, миграции, операции сохранения и
  проверки целостности сохранены без изменения формата проекта.

## Проверки

- Регрессионный тест проверяет отсутствие пользовательских подписей ID и наличие
  ключей в сохранённом и повторно открытом проекте.
- Полный набор тестов и production-сборка выполняются перед фиксацией этапа.
- Реальный файл пользователя используется только для визуальной проверки,
  не изменяется и не добавляется в репозиторий.

## Граница этапа

Диагностический режим для разработчика не добавлялся: в обычном приложении
технические ключи не нужны пользователю и остаются только во внутренних данных.
