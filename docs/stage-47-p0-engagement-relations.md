# Этап P0. Расширение типов партнёрских связей

## Сделано

- В канонической модели добавлен самостоятельный тип `engagement` — «Помолвка».
- Старые типы `marriage`, `partnership` и `unknown` сохраняют прежнее поведение.
- Помолвка доступна:
  - в редакторе существующей связи;
  - в мастере добавления нового человека через партнёрскую связь;
  - в правой панели и семейном статусе;
  - в калькуляторе родства;
  - в SVG/PDF/PNG/TIFF-экспорте через общий текстовый label.
- Для помолвки сохраняются источник, дата начала, точность даты и последующий
  статус завершения через существующую модель истории партнёрства.

## Проверка

- Добавлен `stage-47-engagement-relations.test.mjs`.
- Проверены сохранение и повторное открытие `.familytree`, редакторы,
  калькулятор и экспорт.
- Совместимость браков и партнёрств проверяется существующим полным набором тестов.

## Границы этапа

Типы родительских, братско-сестринских и партнёрских связей теперь представлены
в канонической модели. Следующий этап P0 — довести сценарную матрицу порядка
создания связей до полного набора случаев из дорожной карты и проверить повторное
открытие после каждой операции.
