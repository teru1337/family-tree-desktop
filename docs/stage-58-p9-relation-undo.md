# Этап 58 — приоритет 9: отмена последнего изменения связи

## Что сделано

- После добавления, изменения или удаления связи в уведомлении появляется
  отдельная команда `Отменить связь`.
- Команда использует существующий атомарный Undo/Redo: одновременно
  восстанавливаются люди, связи и запись журнала, поэтому журнал не остаётся в
  противоречивом состоянии.
- Для удаления человека сохранена общая команда `Отменить`, потому что она
  восстанавливает не только связи, но и саму запись человека.
- После отмены доступна штатная команда повторения действия.

## Проверки

- Добавлен тест восстановления предыдущего графа связи вместе с журналом.
- Добавлена проверка наличия отдельного действия `Отменить связь` в UI.
- Обязательные проверки этапа: `npm test` и `npm run build:renderer`.
