# Этап P3.2 — настраиваемые горячие клавиши

Дата: 25.08.2026

## Что сделано

- Создан единый реестр команд приложения: сохранение, открытие, сохранение
  копии, отмена, повтор, поиск, масштаб, стрелочная панорама, центрирование,
  показ всего дерева и переключение родственной ветви.
- Стандартные сочетания включают `Ctrl+S`, `Ctrl+O`, `Ctrl+Shift+S`, `Ctrl+Z`,
  `Ctrl+Y`, `Ctrl+F`, `+`, `-`, стрелки, `Home`, `Shift+Home` и `Ctrl+B`.
- В настройках проекта можно изменить сочетание, сбросить одну команду или
  вернуть все значения по умолчанию.
- Конфликты между командами блокируют сохранение настроек и объясняются рядом
  со списком.
- Сочетания с клавишей Windows не принимаются, а потенциально системные
  сочетания показывают предупреждение.
- В настройках добавлена краткая инструкция по назначению и сбросу сочетаний.
- Настройки хранятся в необязательном поле `project.settings.shortcuts`.
  Старые проекты без этого поля получают безопасные значения по умолчанию;
  версия формата проекта не увеличивалась.
- Глобальный обработчик не перехватывает сочетания при фокусе на полях,
  кнопках, ссылках и редакторе сочетаний.

## Проверки

- Проверены стандартные значения и нормализация событий клавиатуры.
- Проверены конфликты, сочетания Windows и предупреждения о системных клавишах.
- Проверено сохранение и повторное открытие проекта без поля shortcuts.
- Выполнены полный набор тестов и production-сборка renderer.
- Настройки проверены в Electron: список команд, захват сочетания, сброс и
  сообщение о конфликте.

## Ограничения

- Сочетания с клавишей Windows намеренно не поддерживаются, чтобы не вмешиваться
  в глобальные команды Windows.
- Персональные сочетания сохраняются внутри текущего `.familytree`; для старых
  файлов используются стандартные значения.
