# Этап 55 — P7: дата смерти

## Что сделано

- Добавлено каноническое поле `deathDate` на основе общей модели точности:
  точный день, только год, приблизительная дата и диапазон.
- Добавлены место смерти, причина смерти, источник и комментарий.
- Дата смерти редактируется в мастере добавления и в отдельном редакторе
  раздела «Основная информация».
- Сохранены старые поля рождения и совместимость со старыми `.familytree`;
  пустой `deathDate` не добавляется в старые записи автоматически.
- Валидация блокирует явно невозможную дату смерти до рождения.
- Проверка качества данных показывает предупреждение, если такое противоречие
  уже находится в загруженном файле.
- Возраст рассчитывается диапазоном, если дата рождения или смерти неточная;
  пользователь видит формулировку «около N–M лет».
- На карточке человека появляется знак смерти, а в инспекторе отображаются
  сведения о смерти и возраст.
- Сведения о смерти автоматически отображаются как событие «Смерть» во
  временной шкале без дублирования данных в списке пользовательских событий.

## Формат и совместимость

Номер формата `.familytree` не изменён: новые поля необязательны и добавлены
обратно совместимым способом. Старые файлы открываются без добавления пустой
даты смерти; при наличии новых сведений они сохраняются в каноническом поле
`deathDate`.

## Проверка

- `npm test` — полный набор существующих и P7-тестов.
- `npm run build:renderer` — production-сборка, проверка renderer-бюджета и
  подготовка Sites-сборки.
- Тест P7 проверяет persistence/reopen, все варианты точности, хронологию,
  приблизительный возраст, предупреждения качества и UI-связки.
