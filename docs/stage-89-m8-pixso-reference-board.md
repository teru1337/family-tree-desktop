# Этап M8 — прототипы и визуальные референсы в Pixso/Figma

Статус: завершён локально 26 августа 2026 года.

## Результат

В подключённом Pixso-файле `family-tree-desktop` создан reference board и
отдельные рабочие страницы:

- `M8 — Reference board` — четыре именованных фрейма:
  `Current state — стартовый экран`, `Target state — motion`,
  `Motion states — добавление и zoom`, `Accessibility — reduced motion`.
- `01 — Current state`.
- `02 — Target state`.
- `03 — Motion states`.
- `04 — Accessibility / reduced motion`.

Структура отделяет исходное состояние, целевое состояние, переходные состояния
и доступный вариант без motion. Она используется как handoff-контракт между
Pixso и production-реализацией; финальным источником истины для runtime остаётся
код приложения и его тесты.

## Принципы handoff

- не смешивать данные дерева с декоративными визуальными референсами;
- описывать motion как состояния и переходы, а не как набор несвязанных эффектов;
- для каждого движения иметь reduced-motion трактовку;
- проверять реальный Electron-экран после переноса решения в код;
- не считать пустые или демонстрационные Pixso-фреймы готовым пользовательским
  экраном без последующей визуальной детализации.

## Проверки

- Pixso открыт через MCP/Windows Computer Use; изменения видны в текущем файле.
- На reference board визуально проверены четыре фрейма и их имена.
- В проектный код M8 изменений не вносил; production-проверки остаются за
  реализующими этапами M0–M7 и следующими runtime-этапами.
