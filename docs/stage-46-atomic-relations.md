# Этап P0. Атомарные операции графа связей

## Сделано

- Добавлен чистый модуль `relation-operations.js` с единым транзакционным путём
  для runtime-данных приложения.
- Операции добавления и изменения сначала собирают канонический `relations`,
  затем проверяют инварианты и только после успеха возвращают синхронные
  `people`, `partnerships` и `relations`.
- Поддержаны операции:
  - `upsert` для родителя, ребёнка, брата/сестры, брака и партнёрства;
  - `update` для изменения существующей связи, включая развод;
  - `remove` для удаления одной связи;
  - `remove-person` для удаления человека вместе со всеми связанными рёбрами.
- Добавление нового человека через мастер теперь также использует тот же путь,
  поэтому связь не записывается отдельно от карточки.
- Удаление человека и удаление отдельной связи больше не редактируют зеркальные
  массивы вручную: они пересобираются из канонического графа.
- При ошибке операции состояние приложения не обновляется.

## Проверка

- Проверены последовательности добавления родителя, брата/сестры, партнёра,

- Проверены сохранение и синхронизация всех трёх представлений: `relations`,
