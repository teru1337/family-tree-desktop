# Этап 63: производительность больших деревьев

Выполнено:

- Индекс сворачивания ветвей строит карту детей и активных партнёров один раз;
  проверка всех сворачиваемых корней больше не запускает обход дерева отдельно
  для каждого человека.
- Обход скрываемых потомков стал итеративным с указателем очереди, поэтому не
  создаёт лишнюю стоимость `shift()` на длинных ветвях.
- Индекс связей теперь хранит обратные списки по каждому участнику. При
  перемещении полотна линии выбираются по видимым людям, а не повторным полным
  проходом по всем связям.
- Подписи связей, линии мини-карты и карточки мини-карты мемоизированы; обычный
  pan/zoom не пересчитывает их без изменения соответствующих входных данных.
- Исправлены зависимости мемоизации линий от скрытых ветвей, чтобы оптимизация
  не оставляла устаревшие связи на экране.

Проверка:

- нагрузочный тест обрабатывает цепочку из 8 000 человек и проверяет быстрый
  поиск линий среди 6 000 связей;
- обязательные проверки этапа: `npm test` и `npm run build:renderer`.
