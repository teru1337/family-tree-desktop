# Этап 6 — экспорт

## Цель

Дать маме понятный способ вывести всё дерево из локального проекта в файл для
просмотра, семейного альбома, домашней печати или типографии.

## Форматы

- PNG — растровое изображение текущего полного дерева.
- TIFF — несжатое RGBA-изображение для дальнейшей обработки и типографии.
- PDF-плакат — всё дерево на одном большом листе с сохранением пропорций.
- PDF по листам — разбиение большого дерева на страницы A4, A3 или A2.

Все файлы создаются из текущего дерева, фотографий и выбранного стиля оформления.
Текущая панель просмотра, выбранный человек и масштаб окна не меняют экспортируемый
размер: экспортируется полное полотно дерева.

## Настройки качества

- «Экран» — быстрый файл для просмотра.
- «Печать» — увеличенное разрешение для домашнего принтера.
- «Плакат» — максимальная детализация для большого вывода.

Перед созданием файла приложение показывает расчётный размер изображения в пикселях.
Для многостраничного PDF также показывается число листов.

## Большой плакат и листы

Режим «Большой плакат» создаёт PDF с одной страницей нестандартного размера: ширина
задаётся как большой печатный лист, а высота рассчитывается по пропорциям дерева.

Режим «Листы по страницам» режет изображение на сетку страниц, заполняя неполные
крайние листы белым фоном. Размер бумаги и ориентацию можно выбрать отдельно.

## Ограничения текущего прототипа

- Файл выдаётся стандартным скачиванием браузера; отдельный установщик Windows будет
  сделан на этапе упаковки приложения.
- TIFF создаётся без сжатия, поэтому при качестве «Плакат» он может занимать много
  места.
- Изображения в PDF — растровые JPEG-фрагменты; для первого рабочего варианта это
  даёт предсказуемую печать и переносимость между просмотрщиками.
- Экспорт проверяет полотно полного дерева, но не изменяет сам проект и его резервные
  копии.

## Проверка

Механизм PDF имеет отдельную проверку структуры в
`prototype/tests/exporters-pdf.test.mjs`. В ней проверяются заголовок PDF, каталог,
страницы, количество страниц и таблица перекрёстных ссылок.
