# Этап 61: синхронизация вида дерева и экспорта

Выполнено:

- PDF, PNG и TIFF используют текущий стиль карточек, настройку фотографий и
  выбранные поля карточек.
- Настройка показа прежних фамилий теперь применяется одинаково на полотне,
  в SVG-предпросмотре, в основном потоке экспорта и в фоновом Worker.
- Крупный текст из настроек проекта наследуется как начальный размер шрифта
  экспорта.
- Размер карточек по умолчанию теперь «Как на экране» и учитывает режим
  крупного текста; остальные варианты остаются ручными настройками экспорта.
- Зум, панорамирование, выбранный человек, режим родственной ветви и
  сворачивание ветвей намеренно не экспортируются: файл содержит полное дерево
  и не зависит от временного состояния полотна.

Проверка:

- отдельный тест подтверждает прежние фамилии в SVG и передачу настроек через
  предпросмотр, основной поток и Worker;
- обязательные проверки этапа: `npm test` и `npm run build:renderer`.
