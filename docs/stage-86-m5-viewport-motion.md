# Этап M5 — анимированный zoom/pan

Дата: 26.08.2026

## Результат

Для полотна добавлен единый отменяемый контроллер motion-состояния.

- программные перемещения, центрирование, fit-all, mini-map и возврат к
  выбранному человеку проходят через плавный переход с cubic-out easing;
- zoom-кнопки и горячие клавиши центрируют изменение на центре viewport;
- wheel zoom сохраняет мировую точку под курсором, а Shift+wheel плавно
  перемещает полотно;
- новое wheel-, pointer- или keyboard-действие отменяет незавершённый переход;
- ручной drag отключает анимацию на время захвата указателя;
- `prefers-reduced-motion` переводит контроллер в немедленное применение без
  задержки;
- motion-контроллер вынесен в отдельный manual chunk и не записывает zoom/pan
  в `.familytree`;
- вспомогательные панели и поля не находятся внутри viewport и не получают его
  wheel/pan-события.

- `npm test` — 213/213;

- renderer bundle: `493394 / 500000` байт;
- `git diff --check` — успешно;
- production preview проверен в Windows/Chromium при 1920×1080: стартовый

- pure regression tests проверяют easing, границы прогресса, reduced-motion,
  отмену, cursor anchoring и маршрутизацию zoom/pan-команд.

## Ограничения и следующий этап

Интерактивный drag/zoom не воспроизводился в установленном packaged artifact:
локальная проверка выполнена на production preview Chromium, а поведение
контроллера покрыто unit/source-wiring тестами. Следующий этап — M6: живой фон
стартового экрана с контролем интенсивности, контраста, ресурсов и остановки
при скрытом окне или reduced motion.
