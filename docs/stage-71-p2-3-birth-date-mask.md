# Этап P2.3 — маска точной даты рождения

Дата: 25.08.2026

## Что сделано

- В режиме «Точный день» в редакторе основной информации и мастере добавления
  человека используется цифровая маска `__.__.____`.
- Ввод с клавиатуры и вставка из буфера очищаются до цифр, автоматически
  получают разделители и ограничиваются восемью цифрами.
- Позиция курсора рассчитывается относительно количества введённых цифр, поэтому
  точки не ломают последовательный ввод.
- При потере фокуса поле проверяется существующей календарной валидацией: день,
  месяц, год и високосный день должны быть реальными. Неполное значение остаётся
  в черновике и получает ошибку рядом с полем.
- Каноническое хранение, а также режимы «Только год», «Примерно», «Диапазон» и
  «Неизвестно» не изменены.

## Проверки

- Тесты маски, вставки, курсора, неполной даты и високосного года добавлены в
  `tests/stage-71-p2-3-birth-date-mask.test.mjs`.
- Проверены оба UI-потока ввода даты рождения.
- Обязательные `npm test`, `npm run build:renderer`, `git diff --check` и
  визуальная проверка выполнены перед commit и push.

## Ограничения

- Маска относится только к точной дате рождения. Дата смерти и даты событий
  сохраняют прежний свободный ввод, чтобы не расширять текущий этап.
- Реальный пользовательский `.familytree` в репозиторий не добавляется и не
  изменяется.
