# Этап 62: доступность интерфейса

Выполнено:

- Карточки людей остаются обычными кнопками и получили клавиатурную навигацию:
  стрелки переходят к соседнему человеку в поколении или к ближайшему человеку
  в соседнем поколении.
- Полотно объявлено доступным регионом с подсказкой по управлению, а изменение
  выбранного человека передаётся через `aria-live` для экранного диктора.
- Глобальные стрелки больше не перехватывают клавиши, когда фокус находится на
  кнопке, ссылке или поле формы.
- Для модальных окон добавлены автоматический перенос фокуса внутрь, циклический
  переход Tab/Shift+Tab и возврат фокуса на элемент, открывший окно.
- Усилен видимый фокус у кнопки сворачивания ветви.
- Добавлены режимы `prefers-contrast: more` и `forced-colors: active`: контуры,
  линии связей и приглушённые ветви становятся различимее.

Ограничение:

- Доступность внешнего геокодера и системного диалога выбора файла зависит от
  возможностей Windows и браузерного движка Electron; приложение не подменяет
  их собственными визуальными компонентами.

Проверка:

- добавлены регрессионные тесты клавиатурной навигации, ARIA, focus trap и
  контрастных режимов;
- обязательные проверки этапа: `npm test` и `npm run build:renderer`.
