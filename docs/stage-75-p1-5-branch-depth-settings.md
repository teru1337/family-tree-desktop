# Этап 75 — P1.5: глубина родственной ветви

## Что сделано

- В режиме «Родственная ветвь» селектор глубины содержит значения от 1 до 10
  поколений.
- Подпись «Глубина» отображается над селектором количества поколений.
- Панель режима ветви получает отдельный увеличенный размер; элементы внутри
  выровнены по вертикали, а подпись и значения селектора центрированы.
- Значение глубины хранится в `project.settings.branchDepth` и восстанавливается
  при открытии проекта, восстановлении резервной копии, восстановлении архива и
  применении снимка истории.
- Старые проекты без этой настройки и старое значение `all` получают безопасное
  значение по умолчанию — 10 поколений. Технический формат `.familytree` не
  менялся, существующие поля и идентификаторы сохраняются.

## Проверка

- Добавлены тесты диапазона, нормализации и сохранения настройки проекта.
- Повторно проверены существующие тесты режима родственной ветви и плотного
  дерева.
- Перед завершением этапа выполняются полный набор тестов, production-сборка,
  визуальная проверка на реальном `.familytree` и `git diff --check`.
