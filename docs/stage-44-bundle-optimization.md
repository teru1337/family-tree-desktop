# Этап 44 — оптимизация основного JS-бандла

## Сделано

- Тяжёлый экспорт PDF/PNG/TIFF, предпросмотр и связанные зависимости вынесены в отдельный lazy-chunk `ExportModal`.
- Общая компоновка дерева вынесена в `tree-layout.js`, чтобы основной интерфейс и экспорт использовали один алгоритм без дублирования.
- При открытии экспорта показывается короткое состояние загрузки, затем подгружается прежнее окно экспорта.
- Основной renderer-бандл уменьшен с 522,70 кБ до 499,36 кБ и больше не вызывает предупреждение Vite.
- В production-сборку добавлен лимит основного JS-бандла 500 000 байт.
- Тесты обновлены: проверки экспортного UI читают lazy-модуль, а проверка layout учитывает общий модуль компоновки.

## Проверка

- Полный набор: 70 тестов пройдено.
- Production-сборка проходит с проверкой размера бандла.
- Экспортный chunk собирается отдельно и загружается только при открытии экспорта.
