# Этап 32. Большие деревья и фоновый экспорт

Последний приоритетный блок дорожной карты завершён.

## Что сделано

- Добавлен общий индекс людей и связей для полотна и мини-карты. Рендеринг больше
  не ищет участников связей через повторные проходы по массиву людей.
- Поиск переведён на отложенное обновление, чтобы ввод не мешал перемещению по
  большому дереву.
- PDF/TIFF экспорт запускается в модульном Worker (фоновом процессе браузера),
  а кнопка экспорта показывает текущий этап подготовки.
- Если среда не поддерживает Worker или фоновый экспорт завершается ошибкой,
  приложение автоматически использует проверенный основной поток.
- При многостраничном PDF на каждом листе показывается номер вида «Лист 2 из 12».

## Проверка

- `npm test` — 38 тестов проходят.
- `npm run build:renderer` — production-сборка и Sites-упаковка проходят.
- Отдельные проверки этапа подтверждают индексирование связей, fallback фонового
  экспорта и нумерацию листов.
