# Этап P0.3 — безопасный запуск с программным рендерингом

Дата: 25.08.2026  
Статус: реализован

## Что сделано

- Добавлен аргумент запуска `--safe-mode`.
- Добавлен понятный alias `--software-rendering`.
- Добавлена переменная окружения `FAMILY_TREE_SOFTWARE_RENDERING=1` для
  диагностики в локальной разработке.
- При любом из этих способов запуска Electron вызывает
  `app.disableHardwareAcceleration()` до `app.whenReady()`, поэтому старт не
  зависит от рабочего GPU-процесса.
- В меню и нижней строке приложения показывается, что включён безопасный режим
  и используется программный рендеринг.
- Обычный запуск без аргументов не изменён.

## Как запустить

Для установленного приложения можно добавить к ярлыку аргумент:

```text
FamilyTreeCircle.exe --safe-mode
```

В разработке:

```powershell
npm start -- --safe-mode
```

Альтернативная команда:

```powershell
npm start -- --software-rendering
```

## Ограничения

Программный рендеринг использует CPU вместо GPU и может быть медленнее на
больших полотнах или при интенсивных анимациях. Это аварийный способ запуска,
а не замена исправлению драйвера видеокарты или отсутствующих системных DLL.

Формат `.familytree`, сохранение данных и миграции не менялись.

## Проверки

- `git diff --check`;
