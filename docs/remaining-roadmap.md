# Оставшиеся задачи приложения

Этот файл — рабочий список следующих доработок. После завершения и проверки задачи
её пункт удаляется из файла, чтобы к ней не возвращаться повторно.

## Данные семьи

- Расширить интерфейс выбора всех распространённых типов связей: опекун, сводный брат или сестра, другие особые случаи.

## UI и UX

- Показывать предупреждение о несохранённых изменениях перед выходом, открытием другого проекта и созданием нового дерева.
- Добавить кнопку «Сохранить и добавить ещё одного родственника».
- Добавить фильтры поиска по поколению, типу связи, датам и месту рождения.
- Добавить мини-карту всего дерева.
- Добавить команды «Показать всё дерево», «По центру» и «Вернуться к выбранному человеку».
- Разрешить изменять ширину правой панели.
- Добавить закрытие панелей клавишей Esc и полноценную навигацию клавиатурой.
- Улучшить сообщения об ошибках: объяснять причину и следующее действие.
- Добавить отдельную кнопку отмены после удаления человека или связи.

## Экспорт и производительность

- Автоматически рассчитывать размер большого плаката по количеству поколений.
- Проверять читаемость текста при выбранном масштабе экспорта.
- Провести нагрузочную оптимизацию для деревьев на 100–500 человек.
- Вынести тяжёлый PDF/TIFF-экспорт в фоновый процесс, чтобы интерфейс не зависал.
- Добавить разбиение большого дерева на листы с понятной нумерацией.
- Добавить настройки шрифтов, размера карточек, отступов и плотности связей.

## Исключено по решению пользователя

- Сертификаты и подписи установщика или обновлений.
