## Экспорт и производительность

- Автоматически рассчитывать размер большого плаката по количеству поколений.
- Проверять читаемость текста при выбранном масштабе экспорта.
- Провести нагрузочную оптимизацию для деревьев на 100–500 человек.
- Вынести тяжёлый PDF/TIFF-экспорт в фоновый процесс, чтобы интерфейс не зависал.
- Добавить разбиение большого дерева на листы с понятной нумерацией.
- Добавить настройки шрифтов, размера карточек, отступов и плотности связей.

## Исключено по решению пользователя

- Сертификаты и подписи установщика или обновлений.
