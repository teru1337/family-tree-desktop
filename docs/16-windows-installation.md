# Этап 16 — установка для Windows 10/11

## Что добавлено

Прототип упаковывается как отдельное Windows-приложение на Electron. Приложение
запускает собранный интерфейс локально, без обязательного браузера и без
облачного сервера.

Установщик создаётся в формате NSIS для Windows x64. Он:

- устанавливает приложение в выбранную папку;
- создаёт ярлык на рабочем столе;
- добавляет приложение в меню «Пуск»;
- добавляет удаление через системные настройки Windows;
- не удаляет локальные данные приложения при деинсталляции.

## Сборка

В каталоге `prototype/`:

```powershell
npm install
npm run dist:win
```

Готовый файл появится в `prototype/release/` с именем вида
FamilyTree-Setup-версия.exe. Каталог сборки не добавляется в Git.

## Ограничения текущей версии

- установщик рассчитан на Windows x64;
- подпись сертификатом пока не добавлена, поэтому Windows может показать
  предупреждение SmartScreen при первом запуске;
- автоматические обновления добавлены на следующем этапе и описаны в
  docs/17-releases-and-updates.md;
- пользовательские `.familytree` и резервные копии не входят в установщик и
  исключены из Git.
