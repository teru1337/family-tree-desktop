# Этап M9 — отдельное интро в MP4

Статус: **завершён локально 26 августа 2026 года**.

## Результат

Добавлена самостоятельная HyperFrames-композиция в `media/intro/`:

- `index.html` — обезличенная сцена 1920×1080 с детерминированной paused GSAP
  timeline;
- `DESIGN.md` — storyboard и визуальный контракт;
- `README.md` — команды проверки и рендеринга;
- `family-tree-intro.mp4` — готовый отдельный MP4-артефакт.

Интро не подключается к Electron runtime и не содержит реальных семейных данных.
В сцене используются только карточки `Родитель`, `Партнёр`, `Ребёнок`; связи
заканчиваются на геометрии карточек и остаются читаемыми во время hold-состояния.

## Storyboard

Шестисекундная композиция последовательно показывает спокойный фон, заголовок,
первую ветвь, партнёрскую связь, добавление ребёнка и финальное удержание
схемы. Анимация доступна для seek-проверок через `window.__timelines`.

## Проверки

- `npm run check` в `media/intro/` — HyperFrames lint, runtime, layout, motion и
  contrast: без ошибок и предупреждений;
- финальный MP4: H.264, 1920×1080, 30 fps, 6.0 секунды, 1 020 565 байт;
- FFprobe подтвердил контейнер MP4 и параметры видеопотока;
- контрольный кадр на 3-й секунде визуально проверен: карточки, связи, подписи
  и нижняя маркировка не перекрываются.

Для воспроизводимого рендера используются HyperFrames 0.8.15, Chrome Headless
Shell и FFmpeg; эти инструменты являются локальными зависимостями процесса
создания и не входят в runtime приложения.

## Ограничение этапа

Интро подготовлено как отдельный артефакт для onboarding/marketing-сценариев.
Его подключение к стартовому экрану приложения не входит в M9 и может быть
спланировано отдельным этапом после согласования UX.
