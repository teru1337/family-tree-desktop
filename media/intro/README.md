# Family-tree intro

Standalone HyperFrames composition for M9. This folder is intentionally separate
from `prototype/src` and is not imported by Electron.

Commands:

```text
npm run check
npm run render
```

The expected output is `family-tree-intro.mp4` in this folder. The file is a
derived artifact; `index.html` and `DESIGN.md` remain the source of truth.
